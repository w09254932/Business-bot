# Telegram Business Monitor

بوت Telegram Business مبني باستخدام Python وFastAPI.

## الوظائف الحالية
- استقبال تحديثات Telegram Business.
- أرشفة الرسائل الواردة والصادرة والتعديلات في قناة Telegram مركزية.
- نشر إشعارات الحذف كرد على المنشورات المؤرشفة.
- إشعارات الرسائل الجديدة والمعدّلة والمحذوفة.
- إعادة إرسال الوسائط المتاحة باستخدام Telegram file_id.
- وحدة مستقلة لمحاولة استعادة الوسائط الموجودة في الرسائل المردود عليها.
- دعم الصور والفيديو والصوت والملفات والملصقات.
- منع معالجة التحديث نفسه مرتين.
- تنظيف النسخ المؤقتة وفق مدة الاحتفاظ والحد الأقصى.
- حماية Webhook باستخدام Telegram secret token.

## التخزين والأرشفة
- عند ضبط FIREBASE_SERVICE_ACCOUNT_JSON تُحفظ اتصالات Telegram Business في Firestore.
- مسار الاتصالات: users/{owner_id}/business_connections/{connection_id}.
- تُستعاد الاتصالات المحفوظة عند بدء التطبيق.
- عند عدم ضبط متغير Firebase يعمل التطبيق في وضع RAM فقط.
- عند تفعيل Firebase تُحفظ لقطات الرسائل ونصوصها ومعرّفات الوسائط في مجموعة messages، وتخضع لمدة الاحتفاظ المحددة للحساب.
- عند عدم تفعيل Firebase تبقى لقطات الرسائل في RAM وتُفقد عند إعادة التشغيل.
- لا تُحفظ ملفات الوسائط الثنائية داخل Firestore؛ يُحفظ file_id الخاص بوسيط Telegram.
- عند ضبط ARCHIVE_CHANNEL_ID تُنشر الرسائل الواردة والصادرة والتعديلات في قناة الأرشيف.
- تُحفظ معرّفات منشورات القناة وحالة الحذف في مجموعة message_archive المستقلة عن اللقطات المؤقتة.
- تُنشر إشعارات الحذف كرد على منشورات الأرشيف، وتبقى المنشورات المؤرشفة في القناة.
- يتطلب الربط الدائم بين الرسائل ومنشورات الأرشيف تفعيل FIREBASE_SERVICE_ACCOUNT_JSON.

## التشغيل المحلي
1. انسخ `.env.example` إلى `.env`.
2. أدخل BOT_TOKEN وWEBHOOK_SECRET وARCHIVE_CHANNEL_ID. قيمة الأرشيف الحالية: -1002377381147.
3. ثبّت المتطلبات:

   `python -m pip install -r requirements.txt`

4. شغّل التطبيق:

   `uvicorn app.main:app --reload`

5. شغّل الاختبارات:

   `python -m pytest -q`

## النشر على Render
- أمر التشغيل:
  `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- يتطلب BOT_TOKEN وWEBHOOK_SECRET، ويستخدم ARCHIVE_CHANNEL_ID لتحديد قناة الأرشيف.
- يستخدم التطبيق RENDER_EXTERNAL_URL لتسجيل Webhook عند التشغيل.
- مسار فحص الصحة: `/health`.

## قيود مهمة
- عند تفعيل Firestore تُستعاد اتصالات Business واللقطات المحفوظة منه؛ أما وضع RAM فقط فيفقد بيانات الذاكرة عند إعادة التشغيل.
- استعادة الوسائط المؤقتة ليست مضمونة؛ تعتمد على البيانات التي يتيحها Telegram للبوت.
- تحديثات الحذف لا تتضمن محتوى الرسالة؛ يعتمد إشعار الأرشيف على سجل الربط المحفوظ في Firestore، بينما تعتمد استعادة الوسائط على اللقطة المؤقتة.
- قناة Telegram هي مكان الاحتفاظ بالنسخ المؤرشفة، بينما يحتفظ Firestore بمعرّفات الربط وحالة الأرشفة.
